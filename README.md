## Sobre o Projeto

Este projeto integra o ensino técnico de **Engenharia de Software** e **Banco de Dados** com a conscientização cidadã sobre convivência virtual, assédio e cyberbullying. 

Desenvolvido para turmas de Desenvolvimento de Sistemas da **EEB Prof. Ângelo Cascaes Tancredo** sob coordenação do **Prof. Eduardo Kazenski**, o sistema opera como uma plataforma completa de ingestão, gerenciamento e análise de dados abertos e anônimos.

### Objetivos Didáticos e Sociais
- **Engenharia de Dados Prática:** Os alunos atuam como Analistas/Engenheiros de Dados Juniores, vivenciando o ciclo de vida completo da informação (*Modelagem de Schema -> Ingestão/ETL -> Consultas SQL -> Visualização de Métricas*).
- **Especificação de Tipos de Dados:** No painel administrativo, os alunos definem e tipam os campos relacionais (`VARCHAR`, `INT`, `BOOLEAN`, `TEXT`) e restrições de tamanho de caracteres (`tamanho_max`).
- **Conformidade com a LGPD & ECA Digital:** Aplicação dos princípios de *Anonymization by Design* e minimização de dados da **LGPD (Lei nº 13.709/2018)** e alinhamento com o **Estatuto Digital da Criança e do Adolescente (Lei nº 15.211/2025)**.

---

## Arquitetura da Solução

O sistema adota uma arquitetura **Jamstack / Serverless** moderna, eliminando a necessidade de servidores backend dedicados locais durante as aulas e permitindo execução 100% online hospedada via **GitHub Pages**.
